# Electron 浏览器项目计划

## 1. 项目目标

通过可编程浏览器学习 Electron，优先跑通构建、安装与发布，再逐步补齐浏览器和自动化能力。界面只包含标签栏、地址栏、侧边面板与设置，网页内容由网站提供。

- 第一版：安装发布、多标签、独立会话、权限、下载、状态保存与崩溃恢复。
- 第二版：分屏、多窗口、网络工具、系统集成与资源管理。
- 第三版：自动化工具接口、人工接管、执行记录与回放。
- 平台：先完成 Windows，后续适配 macOS、Linux。

## 2. 当前基础与架构

- 已创建 electron-vite + React + TypeScript 项目，使用 pnpm。
- 已接入 electron-builder、shadcn/ui 与 Tailwind CSS，保留最小应用首页。
- 当前版本为 `1.0.1`，安装包通过 GitHub Releases（`liyao1520/electron-browser`）发布，appId 为 `com.liyao1520.ebrowser`。
- `BrowserWindow` 承载本地界面，每个网页标签使用一个 `WebContentsView`。
- 主进程负责窗口、标签、会话、权限、下载、持久化与自动化。
- preload 只向本地界面暴露必要的业务接口；renderer 负责显示状态与发出操作请求。
- 普通工作空间使用 `persist:<workspaceId>` 分区；临时空间使用独立内存分区。

## 3. 完整功能清单

优先级：P0 为第一版必做，P1 为浏览器增强，P2 为自动化。所有条目均为待实现目标。

### 3.1 构建、安装与发布 P0

- [ ] 固定 appId、应用名称、图标、版本号及 Windows 应用标识。
- [ ] 区分开发运行、代码构建、未安装应用目录和安装包，配置各自的资源路径。
- [ ] 生成 Windows NSIS 安装包，支持安装、快捷方式、覆盖安装与卸载。
- [ ] 配置与日志写入用户数据目录，升级保留数据，卸载时明确数据保留策略。
- [ ] 添加单实例控制，重复启动时唤起已有窗口。
- [ ] 接入 CI：锁定依赖安装、lint、类型检查、构建与安装包归档。
- [ ] 使用版本标签触发构建，记录发布说明，配置实际发布源；正式分发接入代码签名。
- [ ] CI 密钥与签名凭据通过 Secrets 注入，客户端不内置发布凭据。

### 3.2 标签、导航与地址栏 P0

- [ ] 新建、切换、关闭、拖动排序标签，恢复最近关闭的普通标签。
- [ ] 显示标题、网站图标、加载状态和导航失败状态。
- [ ] 地址栏支持 URL、缺省协议补全与搜索词，提供前进、后退、刷新和停止。
- [ ] 主进程同步当前 URL 和可前进后退状态，处理重定向与页面内导航。
- [ ] 窗口缩放时更新网页视图尺寸；关闭标签时关闭 webContents 并清理监听器。
- [ ] 设置主页、新标签页及启动时是否恢复上次浏览。

### 3.3 窗口、弹窗与分屏 P0 / P1

- [ ] P0：处理 `window.open`，区分新标签和登录弹窗，保留所属工作空间与必要的 opener 关系。
- [ ] P0：保存窗口位置、尺寸和最大化状态，处理网页关闭请求与退出前未保存表单提示。
- [ ] P1：新建窗口、标签移入新窗口、跨窗口转移标签，避免重复创建或遗漏销毁。
- [ ] P1：双页分屏、切换焦点、调整比例和退出分屏。
- [ ] P1：处理全屏、网页全屏和多显示器下的窗口恢复。

### 3.4 工作空间与临时浏览 P0

- [ ] 创建、重命名、切换和删除工作空间，显示标签所属空间。
- [ ] 工作空间隔离 Cookie、登录状态、缓存、网站存储、权限与代理设置。
- [ ] 同一工作空间内共享登录状态；重启后保留普通空间登录。
- [ ] 临时空间不保存标签、历史和恢复记录，关闭后清理其存储与相关视图。
- [ ] 提供按空间清理 Cookie、缓存和网站数据的入口；删除空间前说明影响。
- [ ] 临时浏览中主动下载的文件单独处理，不将“不保存浏览记录”等同于“不产生文件”。

### 3.5 网站权限与安全隔离 P0

- [ ] 网页禁用 Node.js 集成，开启 contextIsolation、sandbox，保持 webSecurity。
- [ ] 网页不使用本地界面的 preload，不获得文件、系统或通用 IPC 权限。
- [ ] 收紧模板中面向本地界面的通用 IPC 暴露，按业务方法校验发送方、参数与目标标签。
- [ ] 每个 session 同时处理权限检查和权限请求，默认拒绝未支持的权限。
- [ ] 摄像头、麦克风、位置、通知等权限按工作空间和来源授权，可查看和撤销。
- [ ] 校验导航、弹窗和外部协议，禁止网页导航到本地应用界面或任意本地文件。
- [ ] 外部程序调用需校验协议并确认；证书错误不默认放行，本地界面配置 CSP。

### 3.6 下载管理 P0

- [ ] 下载面板展示文件名、来源、路径、进度、速度与完成或失败状态。
- [ ] 支持保存位置选择、默认下载目录、暂停、继续与取消，失败时提示重新下载。
- [ ] 支持打开已完成文件和所在目录，完成后可发送原生通知。
- [ ] 明确关闭标签、关闭窗口和退出应用时的下载行为；退出前提示未完成任务。
- [ ] 保存普通下载记录，处理目标文件已删除的情况；跨应用重启续传作为后续增强。

### 3.7 网络、代理与请求工具 P1

- [ ] 工作空间独立配置系统代理、直连或自定义代理，处理代理认证和连接失败。
- [ ] 观察请求 URL、方法、状态、耗时与失败原因，提供筛选、清空和日志导出。
- [ ] 提供启停明确的 URL 拦截规则，避免误伤主界面请求。
- [ ] 按需导出网络诊断记录，记录中隐藏凭据、Cookie 等敏感信息。

### 3.8 浏览记录、收藏与设置 P0 / P1

- [ ] P0：持久保存普通标签 URL、顺序、活动标签及空间归属，写入失败可恢复。
- [ ] P0：设置主页、启动恢复、下载目录与工作空间管理。
- [ ] P1：浏览历史查询、按条删除与清空；收藏新增、编辑、删除和文件夹。
- [ ] P1：设置搜索引擎、默认缩放、主题，以及数据导入导出。
- [ ] 数据结构包含版本号，为后续升级预留迁移流程；损坏数据不阻止应用启动。

### 3.9 页面工具与系统集成 P1

- [ ] 页内查找、上一个和下一个匹配、页面缩放与恢复默认缩放。
- [ ] 打印、PDF 导出，选择保存路径并展示结果。
- [ ] 常用快捷键：新建及关闭标签、恢复标签、聚焦地址栏、刷新、查找和切换标签。
- [ ] 右键菜单：复制链接、打开新标签、复制粘贴、保存图片等，依据上下文显示。
- [ ] 支持网址拖入导航、链接拖入新标签；本地文件仅在明确的用户操作下打开。

### 3.10 崩溃恢复与资源管理 P0 / P1

- [ ] P0：监听页面加载失败、渲染进程崩溃与无响应，提供重试或重建标签入口。
- [ ] P0：正常退出和异常退出后恢复普通标签元数据；恢复不保证网页表单与内存状态。
- [ ] P0：恢复失败时进入空白窗口或安全启动入口，避免启动后反复崩溃。
- [ ] P1：展示标签关联进程的资源指标，明确标签与进程可能并非一一对应。
- [ ] P1：后台标签休眠与唤醒，允许固定重要标签；清理失效视图、监听器与自动化连接。

### 3.11 自动化工具接口 P2

- [ ] 提供创建和选择标签、导航、观察页面、截图、点击、输入、滚动和结果断言。
- [ ] 优先支持元素定位，补充坐标操作；处理加载等待、超时、元素失效和页面跳转。
- [ ] 支持读取页面结构和可交互元素，按需通过调试协议执行操作。
- [ ] 任务绑定工作空间和标签，复用用户已登录的会话；校验每次操作的目标。
- [ ] 支持开始、暂停、继续、停止和人工接管；人工操作后重新观察页面。
- [ ] 如提供本地工具服务，默认仅监听回环地址，增加鉴权，不向网页暴露调试接口。
- [ ] 提交表单、上传文件、删除等有副作用的操作提供确认点，敏感输入不写入日志。

### 3.12 自动化记录与回放 P2

- [ ] 保存任务、步骤、时间、目标、结果、截图和失败原因，可查看执行时间线。
- [ ] 支持重放选定步骤或从失败步骤重试，执行前检查页面与登录状态。
- [ ] 导出脱敏后的任务记录，区分记录查看与再次执行，避免重复提交有副作用的操作。
- [ ] 临时空间任务记录默认不持久化，截图和日志提供主动保存及清理入口。

## 4. 实施顺序与里程碑

第一版目标约 2～3 周，每天 2～3 小时；时间为估算，以验收通过为准。P1、P2 单独迭代。

| 里程碑          | 预计投入 | 交付与验收                                                           |
| --------------- | -------- | -------------------------------------------------------------------- |
| M0 安装与发布   | 4～5 天  | 空壳安装版完成安装、卸载、覆盖安装及 CI 产物归档                     |
| M1 浏览器核心   | 2～3 天  | 安全边界建立；多标签、地址栏、导航、弹窗可用；连续开关标签无残留视图 |
| M2 会话与下载   | 2～3 天  | 两个空间登录互不干扰；权限可撤销；临时数据不恢复；下载状态可控       |
| M3 第一版验收   | 1～2 天  | 设置及普通标签持久化；模拟标签崩溃可恢复；安装版完成整体回归         |
| M4 浏览器增强   | 后续迭代 | 逐项完成 P1：多窗口与分屏、网络工具、历史收藏、页面工具及资源管理    |
| M5 可编程浏览器 | 后续迭代 | 完成 P2：观察 → 操作 → 验证 → 记录，支持暂停接管及可控回放           |

## 5. 验收原则与范围

- 每个里程碑保留可安装版本；执行 `pnpm lint`、`pnpm typecheck`，按需构建安装包。
- 安装测试使用真实安装包；用干净的 Windows 环境验证不依赖开发机的 Node.js 和源码。
- 网络、登录、权限、下载和崩溃各保留最小人工验收步骤，关键状态逻辑补充必要测试。
- 当前只规划功能，不在此阶段修改业务代码、发布应用或变更项目配置。
- 不自研渲染引擎；Chrome 扩展、账号云同步、密码管理器、全平台一致性不纳入当前承诺范围。
